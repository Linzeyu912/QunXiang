# 📋 群像文档规范

本仓库的本地文档约定。**总规范以统筹仓库 [YingHe信息资产管理规范](https://github.com/Linzeyu912/YingHe) 为准**，此处只列要点精简版。

## 一、frontmatter（YAML）

每个正式 `.md` 头部加：

```yaml
---

created: YYYY-MM-DD
updated: 2026-09-08
tags:
  - 调研          # 调研 / 阶段计划 / 工作流 / 设计 / 进度
  - 群像
---
```

> 当前文件不使用 `type: mirror`，不向统筹仓库复制正文或附件；跨仓引用记录来源仓库、路径和提交号。历史档案保持只读。

## 二、目录结构

- **历史扁平文件**保留原位（有交叉引用，勿搬迁）。
- **新增文档**归入 `docs/{research,plans,workflows,specs}/`，与四仓库统一规范对齐。
- 类别映射见 [README.md](README.md)。

## 三、docx + md 双份

调研报告一律 `名称.docx`（原件）+ `名称.md`（转换版），同名放同目录。
md 的 frontmatter 标注来源：`source: 名称.docx`、`type: docx-converted`。

## 四、语言

- 面向用户的文档、README、调研报告一律**中文**。
- 代码标识符（变量 / 函数 / 类名）保持英文，注释用中文（见仓库根 `AGENTS.md`）。

## 五、提交格式

```
[新增] 添加 XX 调研报告
[更新] 故事切分设计 v2
[同步] 从 YingHe-entity 同步调研
```

## 六、与统筹仓库的关系

- 设计、计划、流程、数据契约和其他工程文档只留在本仓库。
- 调研和阶段进度只在权威分仓维护；YingHe 按路径与提交号引用，不复制正文或附件。
- 工程代码、运行资产和环境按本地[仓库管理规范](仓库管理规范.md)管理；本条与 2026.08.24 跨仓规范对齐。
