# 模型 1：前端 UI 与交互优化交付报告

> 范围：仅 `web/src/**` 与 `web/tailwind.config.js`。未改动任何后端代码、接口契约、锁文件或依赖。
> 所有业务步骤、筛选语义、快捷键、确认流程、SSE 协议、TanStack Query 键与失效语义保持原样。

## 1. 改动摘要

### 设计系统（令牌与基础组件）

- **品牌主色**：由近黑色改为克制的靛蓝（浅色 `243 75% 59%` / 暗色 `234 89% 74%`），焦点环 `--ring` 跟随主色；暗色下主按钮前景用深靛蓝保证对比。
- **语义状态令牌**：新增 `--success` / `--warning` / `--info`（含 `-foreground`），明暗双主题成对定义；Tailwind 配置全部颜色条目改为 `hsl(var(--x) / <alpha-value>)`，使 `bg-success/10` 等透明度修饰真正生效（此前 `/90`、`/15` 修饰被静默丢弃）。
- **修复缺陷**：`ui/select.tsx` 使用了 `bg-popover text-popover-foreground`，但令牌从未定义，下拉内容实际无背景色。已补齐 `--popover` / `--popover-foreground`（暗色为略抬高的表面）。
- **Badge**：`success` / `warning` / `info` 变体改为令牌来源（`bg-success/10 text-success` 等），不再散落 emerald/amber/sky 具体色板。
- **Button**：新增按下态（`active:scale-[0.98]`，禁用时不缩放）；图标按钮从 36×36 提到 40×40，满足触屏最小点击目标。
- **Input / Textarea / Select**：焦点环统一为 2px；输入组件支持 `aria-invalid` 时红色边框。
- **Progress**：补 `role="progressbar"` 与 `aria-valuemin/max/now`。
- **Dialog / AlertDialog**：限制 `max-h-[85vh]` + 内部滚动，宽度 `calc(100vw-2rem)`，360px 窄屏弹窗不再超出视口。
- **动效**：`index.css` 新增 `prefers-reduced-motion: reduce` 全局降级，关闭过渡与循环动画。

### 布局骨架

- `AppLayout`：新增「跳到主要内容」skip link（键盘用户可见），`main` 加 `id="main-content"`；导航项加高至约 36px 并补 `focus-visible` 环；主容器窄屏内边距 `px-4`。
- `App.tsx`：路由分包加载与登录态校验占位改为居中 spinner + 中文文案，不再左上角裸文本。
- `BookLayout`：书籍 Tab 栏改为 `<nav aria-label="书籍功能导航">`，禁用 Tab 加 `aria-disabled`，激活 Tab 加粗字重，焦点环可见。

### 页面

- **登录/注册**：提交错误从纯 Toast 改为表单内联 `role="alert"` 错误条，并通过 `aria-invalid`/`aria-describedby` 与密码字段关联；新增密码显隐切换（可聚焦、带中文 aria-label）；切换登录/注册或修改输入时自动清除错误。
- **书库**：书籍行窄屏允许动作区换行（`flex-wrap` + 内容列 `basis-48`）；图标按钮补 `title`；分享按钮禁用时提示「提取完成后才能分享」。
- **提取管道**：整体进度状态（已完成/失败/进行中）改用语义令牌并置于 `aria-live="polite"` 区；导入提示卡、完成卡、LLM 门禁卡、StageCard 状态色全部令牌化；未开始卡片窄屏可换行。
- **章节**：加载态从一行文字改为贴合双栏布局的骨架；解析失败给出原因与可执行的下一步；章节行加 `aria-current`；噪声告警图标令牌化；`ChapterReader` 找回/待删高亮令牌化，找回按钮去掉 hover 才可见的透明度（触屏可达），加载 spinner 带 `role="status"` 与屏读文本。
- **实体审核**：搜索框与全部筛选下拉补 `aria-label`；虚拟列表行补 `focus-visible` 环；「最新一轮未出现」警告文本令牌化；详情面板共现角色徽标改为真实 `<button>`（键盘可跳转）；编辑表单 Label 补 `htmlFor` 关联；图片缩略图的设主图/删除按钮补 `aria-label` 并支持 `focus-visible` 显现；置信度条令牌化；疑似合并区暗色对比修复（amber 硬编码 → warning 令牌，violet 建议文本补暗色变体）。
- **模型与生成设置**：777 行单文件拆分为组合根（约 90 行）+ `components/settings/` 下四个稳定区块（`TextModelSection`、`ConcurrencySection`、`ImageModelSection`、共享 `ProviderFields` / `SecretInput` / `StatusRow` / `provider-utils`）。保存时机、请求体、预设反推逻辑、并发切换语义逐行保留。密钥显隐按钮不再使用 `tabIndex={-1}`，改为可聚焦按钮 + aria-label；表单 Label 全部关联控件 id；配置错误区加 `role="alert"`。
- **公共素材库**：整张素材卡片改为单个真实 `<button>`（原 div onClick 键盘不可达），图片 `loading="lazy"`；题材/热门/已选标签改为带 `aria-pressed` 的按钮；搜索按钮补 aria-label；空态区分「无条件时无素材」与「筛选无结果」两种文案。
- **素材详情**：加载态换 `DetailSkeleton`；拿取弹窗的目标书下拉补 aria-label。
- **分享给我**：修复加载中闪现「暂无分享」的问题（先显示行骨架）；空态说明来源；「复制中」加 spinner；行布局窄屏可换行。
- **账号**：撤销单个会话、撤销其他会话均增加确认对话框（说明影响范围：该设备/其他设备立即退出）；密码字段补 `autoComplete`；分享码一次性提示框令牌化。
- **导出**：导出类型下拉补 aria-label；清单警告文本与「基于旧版原文」提示改用 warning 令牌；头部窄屏可换行。
- **发布对话框**：标签识别成功条令牌化；题材与自定义标签改为按钮（`aria-pressed` / aria-label）。

### 无障碍与输入设备

- 全站仅图标按钮均有中文 `aria-label` 与/或 `title`；可点击徽标全部改为真实按钮。
- 全站无 `tabIndex={-1}` 滥用（仅剩 skip link 目标与禁用态拖拽区两处正当用法），无裸 `outline:none`。
- 键盘焦点环统一 `ring-2 ring-ring`；列表行用 `ring-inset` 避免被裁剪。

## 5. 剩余风险

- **截图级视觉回归未覆盖**：品牌色从黑白改为靛蓝后，个别仍用琥珀色作装饰的场景（富产物 Sparkles 图标、分层 Tier 徽标的四档色板）是有意保留的非状态色，建议在真机上确认视觉预期。
- **图片设置区的表单回填**：`ImageModelSection` 初始化 effect 与原版一致地在 `status` 引用变化时重填全部字段（保存后若用户继续编辑可能被覆盖）。为保持「不改变保存时机」未修复，如需修复建议加与文本区相同的 `initialized` 哨兵（属行为微调，下轮可做）。
- **LlmSettingsPage 无运行时组件测试**：拆分仅有源码级测试与类型/构建保障，建议补一个 React Testing Library 的保存流程特征测试。
